# Dirección visual: Propuesta B "La cancha al centro"

Documento de desarrollo. Elegida por el usuario entre tres maquetas con estructura distinta
(`frontend/propuestas/a.html`, `b.html`, `c.html`), con la paleta que pidió: verde césped, blanco y negro,
tono deportivo pero de app de reservas (no de tienda).

THESIS: la cancha es la marca y el día es una línea de tiempo; reservar es tocar un bloque verde.
OWN-WORLD: negro #0B0D0C, césped #1F8A3B, verde vivo #22C55E para actuar, blanco para el contenido; Rubik; botones en píldora.
FIRST VIEWPORT (inicio): cancha a pantalla completa, "Juega hoy en Satélite Norte" y el buscador de turnos encima.
FORM: Propuesta B de las maquetas.
